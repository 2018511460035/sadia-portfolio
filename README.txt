Contents
- index.html: the complete responsive portfolio website

Preview locally
1. Extract the ZIP file (if using the ZIP package).
2. Open index.html in a modern web browser.

Publish online
You can publish this folder using GitHub Pages:
1. Create a new GitHub repository.
2. Upload index.html and the assets folder.
3. In the repository, open Settings > Pages.
4. Choose Deploy from a branch, select the main branch and root folder, then save.

The website is a static site and does not require a build step or external JavaScript libraries.
